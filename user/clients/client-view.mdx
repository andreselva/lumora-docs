title: "O que o cliente vê e faz"
description: "Veja o que seu cliente encontra ao abrir o link: as galerias, a escolha das fotos e a revisão do pedido."
---

O cliente abre o link que você enviou, no celular ou no computador. Ele **não precisa criar conta**. O link é a única credencial. Quem tem o link vê todas as galerias do evento.

Para gerar o link, veja [Definir o pacote e compartilhar com o cliente](/user/events/share-with-clients).

## Ao abrir o link

A primeira tela mostra:

- o nome e a data do evento;
- o seu nome, em **Fotos por**;
- até quando o link está disponível;
- a lista de galerias.

O cliente toca em uma galeria para ver as fotos.

## Ver as fotos

As fotos aparecem em uma grade de miniaturas. Ao tocar em uma foto, o cliente a vê maior, com uma marca d'água do Lumora sobre a imagem. Nessa visão ampliada, ele troca de foto pelas setas, pelas setas do teclado ou deslizando o dedo, e fecha com o botão de fechar ou com **Esc**.

A grade só mostra fotos que já ficaram prontas. Uma foto que ainda está sendo processada, ou que falhou, não aparece para o cliente.

<Note>
  A marca d'água aparece na visão ampliada. As miniaturas da grade não têm marca. O arquivo original, sem marca, não é entregue ao cliente pelo Lumora.
</Note>

## Escolher as fotos

Cada foto tem um botão de seleção. O cliente toca nele para marcar ou desmarcar. A marcação funciona também na visão ampliada.

No pé da tela, um contador acompanha a escolha:

| O que aparece | Quando |
| --- | --- |
| `12/30 fotos selecionadas` | O pacote limita as fotos. O primeiro número é o total do evento, somando todas as galerias. |
| `12 fotos selecionadas` | O pacote vende fotos adicionais, então não há limite. |
| **Total: R$ ...** | O valor da escolha até agora, recalculado a cada toque. |
| `N fotos adicionais` | Quantas fotos passam do que o pacote inclui. |
| **Sem valor a pagar** | A escolha cabe no pacote e o pacote já foi pago por fora. |

Quando o pacote limita as fotos e o cliente chega ao limite, o contador avisa: **Você atingiu o limite do pacote. Desmarque uma foto para escolher outra.**

O cliente pode ligar **Só selecionadas** para ver apenas as fotos que já marcou.

A escolha é salva a cada toque. O cliente pode fechar a página e voltar depois com o mesmo link.

<Note>
  O valor que o cliente vê enquanto escolhe é uma prévia. O valor do pedido é calculado pelo Lumora quando o cliente finaliza.
</Note>

## Finalizar o pedido

Quando termina de escolher, o cliente toca em **Revisar pedido**. O Lumora mostra:

- quantas fotos foram selecionadas;
- o valor do pacote, ou **Já pago** quando você marcou que recebeu por fora;
- as fotos adicionais e o valor delas, quando há;
- o **Total**.

Para fechar, o cliente toca em **Finalizar pedido**.

<Warning>
  Depois de finalizar, a escolha **não pode mais ser alterada**. Os botões de seleção ficam desabilitados, e o contador avisa: **Sua seleção foi enviada no pedido e não pode mais ser alterada.**
</Warning>

Com o pedido feito, o botão do contador passa a se chamar **Ver pedido**.

O resultado depende do valor:

| Resultado | O que o cliente vê |
| --- | --- |
| **Pedido confirmado** | Não há valor a pagar: as fotos estão incluídas no pacote. |
| **Pedido registrado** | O pedido está aguardando o pagamento. |

Para escolhas grandes, o Lumora pode levar alguns segundos para preparar o pedido, e a tela espera sozinha. Se mesmo assim o pedido não ficar pronto, a tela avisa que ele ainda está sendo preparado, e o cliente pode tocar em **Ver pedido** de novo para continuar.

## Quando o link não funciona

Se o link venceu, foi substituído por outro, ou o evento não está publicado, o cliente vê **Este link não está disponível** e é orientado a pedir um novo link ao fotógrafo. A tela é a mesma em qualquer um desses casos.

## O que ainda não está disponível para o cliente

| Recurso | Situação atual |
| --- | --- |
| Pagar pelo Lumora | Ainda não está disponível. Um pedido com valor fica aguardando o pagamento. |
| Baixar as fotos originais | Ainda não está disponível. |
| Cancelar o pedido | O cliente não tem esse botão. |

Para acompanhar o que seu cliente escolheu, veja [Ver a seleção do cliente](/user/clients/client-selection) e [Acompanhar os pedidos](/user/orders/orders-list).

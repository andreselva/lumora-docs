O Lumora é uma plataforma para fotógrafos organizarem as fotos de seus eventos. Você cria um evento, separa as fotos em galerias e envia os arquivos direto do navegador. O Lumora recebe cada foto, confere o arquivo e prepara as versões de exibição.

<Note>
  O Lumora está em desenvolvimento. Este guia descreve somente o que está disponível hoje. Recursos que ainda não existem aparecem identificados como tal, para você não procurar por algo que ainda não está no produto.
</Note>

## Como o Lumora organiza seu trabalho

O Lumora usa estes conceitos:

- **Evento**: o trabalho fotografado, como um casamento ou uma formatura. Tem nome, data e uma data de expiração. Todo evento começa como rascunho e precisa ser publicado para o cliente abri-lo.
- **Galeria**: uma divisão dentro do evento, como "Cerimônia" ou "Recepção". Todo evento já nasce com uma galeria chamada **Galeria principal**.
- **Foto**: cada arquivo enviado para uma galeria.
- **Pacote**: o combinado com o cliente para o evento: valor, quantas fotos ele inclui e se há venda de fotos adicionais.
- **Link do cliente**: o endereço que o cliente abre para ver as galerias e escolher as fotos. Não exige conta.
- **Pedido**: o registro que o Lumora cria quando o cliente finaliza a escolha.

## O que ainda não está disponível

Os itens abaixo ainda não funcionam. Alguns aparecem no menu ou em telas do Lumora Studio:

| Recurso | Situação atual |
| --- | --- |
| **Configurações** | O item existe no menu, mas a página ainda não tem conteúdo. |
| Pagamento pelo Lumora | O Lumora registra o pedido e o valor, mas não recebe pagamentos. Um pedido com valor fica em **Aguardando pagamento**. |
| Baixar as fotos originais | O cliente ainda não consegue baixar os arquivos originais. |
| Cancelar um pedido | Nem você nem o cliente têm essa ação na tela. |
| Excluir galerias | Não há essa opção na tela. |
| Mover fotos entre galerias | Ainda não está disponível. |
